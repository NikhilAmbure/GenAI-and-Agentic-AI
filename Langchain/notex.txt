-----------------------------------------
- Langchain : LangChain is an open source framework with a pre-built 
  agent architecture and integrations for any model or tool — so you 
  can build agents that adapt as fast as the ecosystem evolves
- Langchain is helpful to develop application which is LLM powered applications.
- You can integrate 3rd party tools and APIs too. (Integration)
- LangGraph : LangGraph Platform (tool: LangGraph Studio)
- Also, LangGraph helps us to build the AI agents.
- LangSmith : Cloud services (Debugging, Prompt managing, annotation, testing, monitoring)
-----------------------------------------
